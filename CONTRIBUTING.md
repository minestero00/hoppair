# Contributing

Bug fixes, UX improvements, device compatibility reports, and documentation updates are welcome.

1. Open an issue before a large feature or protocol change.
2. Keep each pull request focused. Use English for code comments, UI text, and documentation.
3. Run the checks for the parts you changed; see [development.md](docs/development.md).
4. Include device/OS details for bugs and screenshots for UI changes.

Preserve pending transfers and compatibility between both apps. Add tests for behavior changes; distinguish local emulation from real-device validation.

Keep personal pairing keys, QR screenshots, signing credentials, and local configuration out of Git. Use the deterministic fixtures for protocol tests.

Contributions are provided under the project's [MIT license](LICENSE). Dependencies retain their original licenses.

Questions? Open an issue or email superriaco@gmail.com.
